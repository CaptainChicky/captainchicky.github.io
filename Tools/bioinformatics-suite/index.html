DNA/RNA Mass Calculator

			
Convert between mass (μg/ng), moles (pmol/fmol), and copy number for DNA or RNA
				fragments.
				Paste a sequence (DNA or RNA with U) or enter a length manually. Exact MW is computed when a sequence is
				provided; otherwise an average per-nucleotide mass is used. When ssRNA is selected, any T in the input
				is treated as U for mass calculation.

			
			
			

				
				
				
				
			

			

				
				
				
				
			

			

				
				
			

			

				

				

			

		


		
		

			
Tm Calculator

			
Calculate the melting temperature of an oligonucleotide. Uses the Wallace rule for short
				oligos (≤13 bp), the nearest-neighbor method for primers (14-60 bp), and a long-sequence salt-adjusted
				formula for sequences >60 bp. Supports IUPAC ambiguity codes. Primer concentration is treated as total strand
				concentration (CT).

			
			
			

				
				
				
				
			

			

				
				
			

			

				

				

			

		


		
		

			
Primer Dimer Check

			
Check two primers for potential dimer formation. Highlights complementary regions, especially
				dangerous 3’ end binding that can cause extension artifacts in PCR. Note: IUPAC ambiguity codes (R, Y, S,
				W, etc.) are not supported and will be stripped from input.

			
			
			
			
			

				
				
			

			

				

				

			

		


		
		

			
Sanger Assembly

			
Merge overlapping forward and reverse Sanger reads into a single consensus sequence.
				The reverse read is automatically reverse-complemented, then aligned to the forward read using semi-global
				(overlap) alignment with free end gaps. In the overlap region, IUPAC ambiguity codes are resolved by
				intersection: if one read has N and the other has A, the consensus is A; if one has R (A/G) and the other
				has A, the consensus is A. Conflicts are flagged.

Restriction Sites

			
Scan a DNA sequence against 47 common restriction enzymes. Both strands are searched
				(relevant for enzymes with non-palindromic sites). Shows all enzymes that cut, the number of sites, and
				their positions.
