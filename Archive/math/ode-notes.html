Eliminating First-Order Terms
in Second-Order ODEs

& recovering indefinite integrals from definite forms

Given a differential equation of the following form,

$$y''(x) + y'(x)\, f(x) + y(x)\, g(x) + h(x) = 0$$

for sufficiently "non-exotic" functions $f, g$, and $h$, we seek to kill the first order $y'(x)$ term because without it, the resulting equation

  • Lets you immediately guess solutions like $e^{rx}$, sines, cosines, exponentials, or hyperbolic functions.
  • Often allows factorization of the operator.
  • Makes the equation self-adjoint.

Furthermore, when the equation is self-adjoint

  • Solutions can often be chosen to be orthogonal (like Fourier series or Legendre polynomials).
  • You get nice variational principles (solutions minimize energy functionals).
  • The eigenvalues are real (so oscillations don't grow or decay unless physically intended).
  • Sturm–Liouville theory applies, giving completeness and orthogonality of solutions.
the substitution

We can try to remove the first order term by making the substitution $y(x) \mapsto u(x)$ where for some $v(x)$,

$$\begin{aligned} y &= vu \\ y' &= v'u + vu' \\ y'' &= v''u + 2u'v' + vu'' \end{aligned}$$

Substituting this into the original equation yields

$$\begin{aligned} v''u + 2u'v' + vu'' + (v'u + vu')f + vug + h &= 0 \\ vu'' + (2v' + vf)\,u' + (v'' + v'f + vg)\,u + h &= 0 \end{aligned}$$

Getting rid of the first order term simply means

$$2v' + vf = 0 \;\;\iff\;\; \int\frac{v'\,\text{d}x}{v} = \int -\frac{f}{2}\,\text{d}x \;\;\iff\;\; v = \exp\!\left(\int -\frac{f}{2}\,\text{d}x\right)$$

Hence, the substitution

$$y(x) = \exp\!\left(\int \frac{-f(x)}{2}\,\text{d}x\right)\, u(x)$$
integration constant chosen as $0$

will eliminate the first order term.

Thus $y''(x) + y'(x)\,f(x) + y(x)\,g(x) + h(x) = 0$ under $y(x) = \exp\!\left(\displaystyle\int \frac{-f(x)}{2}\,\text{d}x\right) u(x)$ transforms into

$$\begin{aligned} u'' + \frac{v'' + v'f + vg}{v}\,u + \frac{h}{v} &= 0 \\[6pt] u'' + \left(-\frac{f'}{2} - \frac{1}{4}f^2 + g\right)u + \frac{h}{\exp\!\left(\displaystyle\int \frac{-f}{2}\,\text{d}x\right)} &= 0 \end{aligned}$$

An example is given by $x^2 y''(x) + xy'(x) + (x^2 - \nu^2)y(x) = 0$ where $f = \frac{1}{x}$, $g = \frac{x^2 - \nu^2}{x^2}$, $h = 0$, such that $y = \frac{1}{\sqrt{x}}\,u$ gives us

$$u'' + \left(-\frac{\nu^2}{x^2} + \frac{1}{4x^2} + 1\right)u = 0$$

When $\nu = \frac{1}{2}$, we get $u'' + u = 0$, which becomes trivial to solve.

···

We have some function of 2 or more variables $f$. WLOG let it be a function of just 2 variables $f(t, a)$. Given that the integral converges, if we have a function defined with definite integrals as such

$$A(x, a) = \int_x^k f(t, a)\,\text{d}t$$

for some presumably positive constant $k$ (such as $\infty$) we can adapt it to define the indefinite integral.

Let

$$\int f(t, a)\,\text{d}t = F(t, a) + C(a)$$

where $F(t, a)$ is the main antiderivative, and $C(a)$ is a "constant" with respect to $t$ (when differentiated w.r.t. $t$, $C(a)$ disappears). We know that

$$\begin{aligned} \int_x^k f(t, a)\,\text{d}t = A(x, a) &= F(k, a) - F(x, a) \\ \implies F(x, a) &= F(k, a) - A(x, a) \\ &= G(a) - A(x, a) \end{aligned}$$

We define $F(k, a) = G(a)$ since we are plugging in (or taking the limit) a value $x = k$ into $F(x, a)$, reducing the number of variables to just 1 ($a$ in this case).

Substituting this result back into the indefinite integral, we have

$$\int f(t, a)\,\text{d}t = G(a) - A(t, a) + C(a)$$

Let $C(a) = G(a) + c$, where $c$ is an actual constant (like a numerical value, not a function of any variable). Then

$$\int f(t, a)\,\text{d}t = -A(t, a) + c$$

Note that this works for any function $A$ that is defined with a definite integral such that one of its inputs/variable is a bound of that integral. In this case, $x$ was that variable.

examples

Two examples include the incomplete gamma function

$$\int_x^\infty t^{s-1}e^{-t}\,\text{d}t = \Gamma(s, x) \;\;\iff\;\; \int t^{s-1}e^{-t}\,\text{d}t = -\Gamma(s, t) + C$$

and the inverse Weierstrass elliptic $\wp$ function

$$\int_\infty^z \frac{\text{d}t}{\sqrt{4t^3 - g_2 t - g_3}} = \wp^{-1}(z;\,g_2, g_3) \;\;\iff\;\; \int \frac{\text{d}t}{\sqrt{4t^3 - g_2 t - g_3}} = \wp^{-1}(t;\,g_2, g_3) + C$$

This cannot work with, say

$$\int_0^\infty \frac{1}{\pi}\cos\!\left(\frac{t^3}{3} + xt\right)\text{d}t = \operatorname{Ai}(x)$$

because there is no variable in the bounds, so the constant canceling trick will not work since we can't even substitute the definite integral manipulation into the indefinite integral.
